# Sources and attribution

Candidate facts are derived from linked Wikimedia pages. Each JSONL record
contains the exact Malay Wikipedia revision URL and Wikidata entity used for
verification.

Sparse or current topics may instead cite a first-party official source. Those
records carry the publisher, retrieval date, a short evidence excerpt, and its
SHA-256 so the reviewed evidence is explicit and tamper-evident.

- Wikipedia content is available under the Creative Commons
  Attribution-ShareAlike license; follow the linked revision for attribution
  and history.
- Wikidata structured data is provided under CC0.
- This repository's generated question records remain review-only until owner
  approval.

The repository does not include the local source bank, API caches, secrets,
environment files, or production configuration.
